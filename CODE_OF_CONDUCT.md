# Community code of conduct

Be respectful, evidence-based and constructive. Critique code and clinical reasoning without attacking people. Harassment, threats, discriminatory language, doxxing and publication of private or patient data are prohibited.

Maintainers may edit or remove harmful content and restrict participation proportionately. Raise non-sensitive conduct concerns through an issue requesting private maintainer contact; do not repeat private information publicly. Maintainers should avoid conflicts of interest and explain moderation decisions when doing so does not expose private information.
