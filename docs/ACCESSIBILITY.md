# Accessibility review plan

Implemented foundations: native labels, labelled controls, Android 48dp minimum targets, WPF ≥40px inputs /44px actions, scrollable text, scalable font units, text interpretations independent of color, live-result semantics and standard keyboard focus.

Pending evidence: TalkBack/Narrator reading order and result announcement; keyboard-only completion with visible focus; 200% system font and high DPI; light/dark/high-contrast themes; WCAG-inspired 4.5:1 text contrast and 3:1 control contrast; no clipped long Russian strings; narrow landscape/small screens. WPF button/checkbox labels and Android spinner popups need actual platform inspection. No accessibility conformance claim is made.
