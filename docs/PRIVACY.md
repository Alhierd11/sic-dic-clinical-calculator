# Privacy

Applications calculate locally. No analytics, advertising, tracking, remote crash reporting, cloud database, network calls or AI inference. No INTERNET permission on Android. Android backup is disabled. Inputs remain in process memory and are not automatically persisted; closing/recreating the shell clears them. No patient name or record number fields are requested.

Clipboard copy is an explicit user action and may expose information to OS clipboard services or other apps. The current export includes scores, warnings and provenance, not patient identifiers. Do not enter identifying data in any numeric field. Operating-system screenshots, device compromise, clipboard synchronization, swap and OS crash facilities are outside the application's control. Use managed devices and local policy.

History, share and PDF are not implemented in this milestone. Their future implementation must be opt-in and local, support delete-all, separate cases and avoid system/cloud backup. No case data may be included in public GitHub issues.
