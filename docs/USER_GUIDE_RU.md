# Руководство — версия для разработки

Не используйте эту версию для клинических решений: независимая проверка не завершена.

1. Введите тромбоциты, INR и сумму только четырёх компонентов SOFA для SIC. Укажите, установлен ли сепсис.
2. Для DIC введите D-димер, ВГН того же метода, общую единицу и FEU/DDU. Подтвердите сопоставимость. Неизвестная система блокирует расчёт DIC.
3. Введите ПВ пациента и контрольное ПВ в секундах, фибриноген с выбранной единицей. Укажите наличие заболевания, способного вызвать ДВС.
4. Отметьте беременность, акушерский/послеродовой контекст и детский возраст, если применимо.
5. «Подробно» включает баллы компонентов, отношение D-димера/ВГН и разницу ПВ. Нажмите «Рассчитать». Пустой или некорректный показатель не заменяется нулём.
6. Для копирования нажмите отдельную кнопку. Изменение ввода снимает прежний результат. «Новый пациент / очистить» удаляет текущий ввод.

Десятичная запятая и точка допустимы; разделители тысяч и запись вида <0,1 — нет. SIC/DIC рассчитываются независимо. Численный порог не подтверждает диагноз; низкий балл не исключает заболевание. Контекст и ограничения показаны вместе с результатом.

Время результата — UTC, не время забора анализа. Данные не сохраняются. Перезапуск, смена языка или темы очищают форму в этой версии. История, настройки лаборатории, интерфейс SOFA helper и PDF пока отсутствуют. Источники доступны в окне «О программе» и clinical-spec/SOURCES.md.
